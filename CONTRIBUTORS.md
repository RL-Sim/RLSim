## 📋 How to Become a Core Contributor

To be recognized as a Core Contributor, you should:

1. **Make Sustained Contributions**
   - Submit multiple pull requests (typically 5+)
   - Demonstrate understanding of the project's goals and architecture
   - Show commitment over time (not just one-time contributions)

2. **Participate in Governance**
   - Engage in discussions about project direction
   - Review and provide feedback on other contributions
   - Help maintain code quality and documentation

3. **Take Responsibility**
   - Own major features or components
   - Maintain code quality in your areas
   - Help onboard new contributors

4. **Get Nominated**
   - Be nominated by existing Core Contributors
   - Be approved by the project maintainers
   - Accept the Core Contributor responsibilities

---

## 🎯 Core Contributor Responsibilities

As a Core Contributor, you are expected to:

1. **Maintain Code Quality**
   - Follow project coding standards
   - Write tests for new features
   - Review pull requests from other contributors

2. **Support the Community**
   - Help answer questions from users
   - Mentor new contributors
   - Provide constructive feedback

3. **Advance the Project**
   - Contribute to major features
   - Help with project planning and roadmap
   - Participate in architectural decisions

4. **Uphold the License**
   - Respect the RLSim License terms
   - Ensure contributors understand the license
   - Report license violations
