# How-To Guides

Task-oriented guides that solve specific problems and answer "how do I...?" questions.

## Purpose

How-to guides are practical, goal-oriented documentation that help you accomplish specific tasks.
Unlike tutorials that teach concepts,
how-to guides assume you already understand the basics
and want to solve a particular problem or implement a specific feature.

## When to Use How-To Guides

Use these guides when you:

- Want to add a new traffic rule to the simulator
- Need to customize vehicle behavior
- Are ready to deploy the application
- Have a specific problem to solve
- Know what you want to do but not how to do it
